# KalenderMenu - Android Application

Aplikasi Android untuk manajemen menu kalender menggunakan Jetpack Compose, Dagger Hilt, Room Database, dan TensorFlow Lite (TFLite).

---

## 🚀 Panduan Memulai untuk Tim (Setelah Clone)

Agar proses kompilasi berjalan lancar tanpa terkendala *mismatch* cache atau konflik internal library, ikuti panduan berikut saat pertama kali membuka project ini.

### 1. Prasyarat Lingkungan Build
* **Android Studio:** Ladybug / Koala atau versi terbaru yang menggunakan Gradle modern.
* **JDK Java:** Versi 17 (Wajib disesuaikan pada Gradle Settings).
* **Target & Compile SDK:** 34 (Android 14).
* **Arsitektur Kotlin:** 1.9.25 dengan Compose Compiler 1.5.15.
